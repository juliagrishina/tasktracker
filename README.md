# TaskTracker

Персональный iOS-планировщик, объединяющий личные задачи, напоминания и основной корпоративный календарь Microsoft 365 Outlook.

## Текущий статус

Согласованы информационная архитектура, структура четырёх вкладок и ключевые пользовательские пути MVP. Код приложения ещё не создавался.

## Выбранные варианты

- «План»: дашборд дня.
- `Backlog`: карточки-категории.
- «Завершённые»: история по датам.
- «Настройки»: панель состояния.
