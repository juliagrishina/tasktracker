# TaskTracker

Персональный iOS-планировщик задач с офлайн-первым хранением данных. Приложение
реализуется на Expo, React Native и TypeScript. Подключение Microsoft 365 будет
рассматриваться отдельно после проверки авторизации и не является частью Epic 01.

## Текущий статус

Epic 01 создаёт каркас приложения: четыре вкладки, локальное хранилище SQLite
для iPhone и обязательный браузерный прототип. В браузере используются временные
демонстрационные данные; на iPhone пользовательские записи сохраняются локально
в SQLite.

## Запуск

Требуются Node.js и npm. Из корня проекта выполните:

```bash
npm install
```

Для интерактивного браузерного прототипа на Windows:

```bash
npm run web
```

Откройте адрес Expo из консоли. В веб-версии показаны тестовые карточки для
«Плана», `Backlog` и «Завершённых»; они существуют только в памяти страницы и
пропадают после обновления браузера.

Для проверки на iPhone через Expo Go:

```bash
npm start
```

Откройте QR-код из консоли в Expo Go. На iPhone тестовые web-карточки не
создаются: локальное хранение SQLite проверяется development-кнопкой на экране
«Настройки».
