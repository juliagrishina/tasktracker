# Дополнительно

## Доработка № 1 — действия с задачей из плана дня

**Статус:** Planned · **Связь:** Epic 05, отдельная задача после текущего набора E5-T1–E5-T8.

### Цель

Позволить пользователю прямо из плана дня быстро и безопасно завершить задачу, удалить её или снять с расписания, не переходя в Backlog. Действия должны быть доступны как в редакторе задачи, так и быстрым меню по долгому нажатию.

### Пользовательские сценарии

1. Открыв существующую задачу из плана дня, пользователь видит в редакторе действия «Выполнено» и «Удалить» наряду с «Отмена» и «Сохранить».
2. В плане дня пользователь долго нажимает на временной блок или задачу без времени и получает компактное контекстное меню: «Выполнено», «Вернуть в Backlog», «Удалить».
3. После отметки «Выполнено» задача остаётся видимой в плане выбранного дня: она светло-серая, зачёркнутая и с визуальным признаком завершения.
4. Пользователь различает «Вернуть в Backlog» и «Удалить»: первое снимает задачу с расписания, но сохраняет её; второе удаляет саму задачу после подтверждения.

### Функциональные требования

1. Дополнительные действия доступны только для существующей задачи; форма создания задачи сохраняет текущий набор кнопок.
2. «Выполнено» сохраняет внесённые в форме изменения и затем отмечает задачу завершённой. Для повторяющейся задачи пользователь выбирает область применения: текущий экземпляр или всю серию.
3. «Удалить» требует явного подтверждения. При подтверждении задача удаляется вместе с её планированием; во внутренней модели применяется существующее soft delete.
4. «Вернуть в Backlog» удаляет только планирование: временные блоки, дату/период и связанные правила повторения в пределах выбранной области применения. Сама задача остаётся активной в Backlog.
5. Долгое нажатие на задачу в расписании или в разделе «Без времени» открывает компактное контекстное меню. Удаление из него также требует подтверждения.
6. Завершённая задача сохраняется в плане только выбранного дня, не показывается как активная на следующих днях и не может быть ошибочно принята за незавершённую.
7. Завершённая задача обязательно входит в расчёт загрузки дня: временные блоки учитываются по своей длительности, задачи без точного времени — по оценочной длительности.
8. Завершённая задача в плане выбранного дня отображается светло-серой, с зачёркнутым названием и визуальным признаком выполнения. Она не выглядит как активная задача.
9. Никакое из действий не выполняется автоматически по времени или без явного выбора пользователя.
10. Для завершённой задачи в редакторе доступно действие «Возобновить». В плане дня и во вкладке «Завершённые» долгое нажатие на завершённую задачу открывает действия «Возобновить», «Вернуть в Backlog» и «Запланировать».

### Не входит в scope

- автоматическое завершение по окончании блока;
- новый архив, поиск или удаление записей архива Epic 06;
- фоновый трекер времени;
- Outlook/Microsoft 365 и облачная синхронизация;
- изменение логики локальных уведомлений сверх корректной реакции на уже существующее завершение или удаление.

### Критерии готовности

- [ ] В редакторе существующей задачи из плана доступны «Отмена», «Сохранить», «Выполнено» и «Удалить»; форма создания не меняется.
- [ ] Долгое нажатие на временной блок и на задачу без времени открывает меню с действиями «Выполнено», «Вернуть в Backlog» и «Удалить».
- [ ] «Выполнено» оставляет задачу в плане выбранного дня в сером зачёркнутом состоянии и учитывает её в загрузке дня.
- [ ] «Вернуть в Backlog» удаляет планирование, но сохраняет задачу в Backlog.
- [ ] «Удалить» показывает подтверждение и после него удаляет задачу и её планирование.
- [ ] Повторяющееся дело всегда получает выбор области применения; соседние экземпляры не меняются без подтверждения.
- [ ] Действия доступны с клавиатуры и имеют понятные accessibility labels.
- [ ] Возобновлённая задача снова активна; при возврате в Backlog её размещение снято, при выборе «Запланировать» открывается форма планирования.
