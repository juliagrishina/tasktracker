# Статус этой директории

- `ТЗ_iOS_планировщик_MVP.docx` — **исторический документ**: снимок первоначального черновика требований на момент начала планирования продукта.
- Он **не является актуальным источником требований** и не обновляется вручную под новые решения.
- **Агенты и разработчики не должны использовать `.docx` для принятия архитектурных или продуктовых решений** при разработке. Любое требование, поведение или архитектурное решение должно опираться только на `docs/tz/`.
- При любом расхождении между `.docx` и `docs/tz/` **приоритет всегда имеют актуальные документы `docs/tz/`** — `.docx` в этом случае игнорируется.

Актуальный и канонический источник требований — `docs/tz/epic-00-overview.md` и связанные `docs/tz/epic-*.md`, включая [«Аккаунт, данные и облачная архитектура»](../tz/account-data-and-cloud-architecture.md) как единый источник истины по модели идентичности, владения данными и облачной архитектуры.

`.docx` сохранён в репозитории только как историческая отправная точка, а не как параллельно поддерживаемая спецификация — во избежание двух независимо расходящихся описаний архитектуры он не редактируется и не синхронизируется построчно с `docs/tz/`.
