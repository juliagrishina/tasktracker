Общие состояния, диалоги и ошибки

Эти элементы переиспользуются в нескольких сценариях.

Модальные формы и sheets

SheetСоздание и редактирование проекта, задачи, подзадачи или напоминания.
SheetПланирование: дата, период, блоки времени, повторение.
MenuПереключатель вида содержит ровно «День / Неделя / Месяц».
PromptНеблокирующая оценка энергии при первом открытии дня.

Подтверждения и правила

Серия«Только этот экземпляр / Всю серию / Отмена».
УдалениеПодтверждение для архива и локальных данных Outlook.
ПереносНеобязательная причина; история переноса сохраняется.
ВечерНезавершённые дела без времени проверяются в 21:00.

Ошибки синхронизации

Нет сетиПоказать сохранённый план и статус «Не удалось обновить».
ТокенСначала тихое обновление; затем предложить повторный вход.
ПолитикаОбъяснить необходимость обратиться к IT-администратору.
ЛимитПовтор с увеличивающейся задержкой; успех только после всех страниц.
Граница MVP: без drag-and-drop, поиска в Backlog, видимых статусных плашек, процентов выполнения отдельных задач, редактирования Outlook и отдельной кнопки быстрого Backlog поверх плана. Все основные экраны рассчитаны на вертикальный iPhone и Dynamic Type.
