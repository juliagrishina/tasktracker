# Визуальная схема интерфейса

HTML-макеты сохраняют все варианты, показанные и согласованные во время `superpowers:brainstorming`. Они автономны: файл можно открыть напрямую в браузере и выбирать карточки кликом или клавишами Enter/Space.

## Варианты экранов

- [Главная «План — День»: три варианта](mockups/home-options.html) — выбран B, дашборд дня.
- [Backlog: два варианта](mockups/backlog-options.html) — выбран 2, карточки-категории.
- [Завершённые: два варианта](mockups/completed-options.html) — выбран 1, история по датам.
- [Настройки: два варианта](mockups/settings-options.html) — выбран 2, панель состояния.
- [Итоговая карта экранов и пользовательских путей](mockups/user-flow-map.html).

Текстовые требования, пограничные состояния и критерии проверки зафиксированы в [дизайн-спецификации](../superpowers/specs/2026-08-01-ios-planner-interface-design.md).
