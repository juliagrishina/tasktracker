# Epic 05 — корректировки уведомлений и завершённых дел

> **Для Codex:** выполнить пункты плана последовательно в одной ветке `codex/epic-05-t1-t9`; это одна согласованная корректирующая Task.

## Цель

Исправить жизненный цикл уведомлений повторяющихся дел в скользящем горизонте 90 дней, вывести реальные завершённые дела в отдельную вкладку и дать пользователю возобновление/перенос завершённого дела без потери его истории в плане дня.

## Шаги

1. Добавить тесты приложения на отмену и пересоздание уведомлений при изменении экземпляра повторения, завершении, отмене и сдвиге серии; реализовать единый пересчёт уведомлений на 90 дней при запуске и изменении серии.
2. Добавить тесты и use cases для реальной истории завершённых обычных и повторяющихся дел, а также возобновления: в план с сохранением размещения и в Backlog с удалением размещения.
3. Добавить UI-тесты для редактора и long-press действий, реализовать доступные действия в плане и «Завершённых», затем актуализировать ТЗ Epic 05 и дополнительное ТЗ.
4. Выполнить только целевые тесты затронутых модулей и `npm run typecheck`; закоммитить и отправить ветку.

## Границы

- Серии уведомлений не создаются «навсегда»: планировщик хранит конкретные уведомления только для ближайших 90 дней и пересинхронизирует их при старте приложения и каждом изменении серии.
- Завершённая задача остаётся в плане выбранного дня с существующей визуальной меткой и дополнительно появляется во вкладке «Завершённые».
- Возобновление серии применяется к выбранному экземпляру; действие для всей серии изменяет только будущие экземпляры и не затрагивает явно завершённые прошлые экземпляры.
