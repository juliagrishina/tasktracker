# Ручная проверка UI foundation

Проверка проводится после `npm run web` и отдельно на iPhone через Expo Go (`npm start`). Она не заменяет сценарии из чек-листов Epic 01 и Epic 02.

## Общие визуальные правила

- [ ] Видны четыре вкладки: «План», Backlog, «Завершённые», «Настройки».
- [ ] Активная вкладка синяя (`#0A84FF`), неактивные — нейтральные; нижняя навигация не конфликтует с iOS safe area.
- [ ] Экран использует светлый canvas, белые поверхности, тонкие серые границы и системную типографику без индиго из прежнего временного интерфейса.
- [ ] Кнопки, карточки и элементы формы имеют минимальную touch-зону 44×44 pt.

## Backlog — вариант 2

- [ ] Корень показывает ровно три карточки в порядке «Напоминания → Без проекта → Проекты».
- [ ] Каждая карточка показывает semantic glyph, количество, не более двух preview rows и явный переход; у проектов текст «Перейти к проектам».
- [ ] В Backlog нет поиска и фильтров.
- [ ] `+` открывает выбор «Новый проект», «Новая задача», «Новое напоминание».
- [ ] Создание, редактирование, перемещение, завершение и подтверждённое удаление продолжают работать на web и iPhone.
- [ ] Sheet корректно прокручивается и не скрывает активное поле за клавиатурой iPhone.

## Web

- [ ] Проверить ширины 320, 375, 414, 768, 1024 и 1440 px: нет горизонтальной прокрутки, контент не обрезается.
- [ ] Интерактивные элементы доступны клавишей Tab в визуальном порядке; focus остаётся заметным.
- [ ] Сценарии Backlog выполняются мышью/trackpad и клавиатурой; hover не является единственным индикатором действия.

## iPhone

- [ ] Открыть приложение в Expo Go, пройти Backlog и проверить safe areas вверху и у нижней навигации.
- [ ] Нажать `+`, открыть форму, ввести текст и проверить numeric keyboard для длительности.
- [ ] Проверить, что удобны нажатия кнопок «Назад», «Закрыть форму», «Сохранить», «Завершить» и «Удалить».

## Границы этой поставки

- [ ] «План B», «Завершённые 1» и «Настройки 2» не получают фиктивные элементы управления до реализации их данных и сценариев в соответствующих эпиках.
- [ ] Нет production backend, авторизации, синхронизации, push notifications, Microsoft 365/Outlook-подключения, планирования времени или поиска архива.
