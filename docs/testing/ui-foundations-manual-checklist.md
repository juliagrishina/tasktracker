# Ручная проверка утверждённого UI

Проверка проводится после `npm run web` и отдельно на iPhone через Expo Go (`npm start`). Она дополняет автоматические тесты и чек-листы Epic 01/02.

## Общие правила

- [ ] Видны четыре вкладки: «План», Backlog, «Завершённые», «Настройки»; активная вкладка синяя, inactive — нейтральная.
- [ ] Используются светлый canvas, белые поверхности, тонкие границы и системная типографика утверждённого визуального языка.
- [ ] Интерактивные элементы имеют touch-зону не менее 44×44 pt, а safe areas не перекрывают содержимое.

## План B

- [ ] Видны «Сегодня», дата, pill «День», refresh, progress ring 35 %, карточка «План в норме», «Без времени» и «Расписание».
- [ ] Действия заголовка и floating `+` показывают только локальную demo-обратную связь и не меняют данные.

## Backlog 2

- [ ] Корень показывает карточки «Напоминания → Без проекта → Проекты» с числом, preview-строками и переходом.
- [ ] Видны subtitle, информационный callout и `+`; поиск и фильтры отсутствуют.
- [ ] Уже реализованные сценарии создания, редактирования, перемещения, завершения и подтверждённого удаления продолжают работать.

## Завершённые 1

- [ ] Видны поле «Поиск по названию», выбранная «Неделя», группы «Сегодня» и «Вчера · 2 августа», типовые glyphs и notice о подтверждении удаления.
- [ ] Поиск фильтрует только demo archive; period tabs и `…` меняют только локальное визуальное состояние, ничего не удаляют.

## Настройки 2

- [ ] Видны Microsoft 365, статус «Подключён», «План дня», «Уведомления», «Данные Outlook» и версия приложения.
- [ ] «Обновить сейчас», «Управление», «Изменить» и «Удалить локальные данные» показывают demo feedback без сети, авторизации, синхронизации, сохранения или удаления.

## Web и iPhone

- [ ] На web проверить 320, 390, 768, 1024 и 1440 px: нет горизонтального scroll и содержимое не обрезается.
- [ ] На wide web композиция ограничена по ширине и центрирована временно; это не проверка финального desktop-макета.
- [ ] На iPhone пройти все четыре вкладки, проверить safe areas, scrolling и удобство touch targets.
- [ ] На web проверить Tab-порядок и видимый focus; hover не остаётся единственным сигналом действия.

## Вне scope этого этапа

- [ ] Нет production backend, авторизации, Microsoft 365/Outlook-подключения, синхронизации, push notifications, production-планирования, постоянного редактирования настроек или реального удаления archive-данных.
