# Epic 01 — ручная проверка

## Браузерный прототип

1. Запустите `npm run web` на Windows и откройте URL Expo в браузере.
2. Подтвердите, что «План», `Backlog`, «Завершённые», «Настройки» отображаются именно в этом порядке.
3. Убедитесь, что в «Плане», `Backlog` и «Завершённых» показаны тестовые карточки браузерного прототипа.
4. Откройте каждую вкладку и обновите страницу браузера. Убедитесь, что нет формы входа, элементов Microsoft 365 или данных Outlook.
5. Откройте «Настройки», нажмите «Проверить хранение» и убедитесь, что появляется «Тестовые данные созданы». Обновите страницу: результат должен исчезнуть, потому что браузерное хранилище временное.

## iPhone и локальное хранение

1. Выполните `npm start`, откройте проект в Expo Go на iPhone и посетите все четыре вкладки.
2. Убедитесь, что на iPhone «План» открывается первым и отображает пустое состояние без тестовых web-карточек.
3. На «Настройках» в development-режиме запустите проверку хранения. Первый запуск должен показать «Тестовые данные созданы».
4. Перезапустите Expo Go, снова откройте «Настройки» и повторите проверку. Результат должен измениться на «Локальное хранение подтверждено».

## Ограничения Epic 01

- В веб-версии данные живут только в памяти страницы и не переживают обновление браузера.
- На iPhone SQLite используется для локального хранения; синхронизации, входа, Microsoft 365 и Outlook в Epic 01 нет.
- Разработка создания и редактирования задач, напоминаний и настроек будет выполнена в последующих эпиках.
