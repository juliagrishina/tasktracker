# Epic 03 — ручная приёмка планирования

## Подготовка

1. Выполните `npm ci` и `npm run web` из корня репозитория.
2. Откройте адрес Expo Web в браузере с шириной окна 390 px.
3. Начните сценарий с новой страницы: web-источник хранит данные только в памяти текущей вкладки.

## Браузерный маршрут

1. В Plan нажмите «Добавить в план», создайте задачу с названием и добавьте два блока времени на пяти‑минутной сетке. Сохраните и убедитесь, что оба блока появились в расписании выбранного дня.
2. Создайте второй блок, пересекающийся с уже сохранённым. В предупреждении сначала выберите «Отменить» и убедитесь, что блок не появился. Повторите действие и выберите «Сохранить с пересечением»; блок должен появиться.
3. В Backlog создайте напоминание по дате, затем напоминание по периоду и повторяющееся напоминание. Проверьте сохранённые дату/период/повторение после закрытия формы.
4. В форме напоминания выберите «Добавить время», укажите дату, время и проект (либо «Без проекта»), подтвердите преобразование. Убедитесь, что напоминание исчезло, а задача с блоком появилась в выбранном проекте или без проекта.
5. Откройте повторяющуюся задачу для конкретной даты, выберите «Только этот экземпляр» и сохраните. Проверьте, что исключение создано только для этой даты, а правило всей серии и следующий экземпляр не изменены.
6. Перейдите в «День», «Неделя» и «Месяц». Убедитесь, что одни и те же сохранённые блоки определяют загрузку. Для суммарной длительности более рабочего дня процент должен быть выше 100 %, без ограничения значением 100.

## Визуальная и доступностная проверка

1. На ширине 390 px проверьте отсутствие горизонтальной прокрутки, видимый фокус при клавиатурной навигации и интерактивные области не меньше 44 pt.
2. Убедитесь, что кнопки решения конфликта различимы и остаются доступны до закрытия формы.
3. На широком окне проверьте сохранение временной центрированной мобильной композиции.

## iPhone / SQLite

1. Запустите `npm start`, откройте проект через Expo Go на iPhone и повторите базовый маршрут создания блока и повторения.
2. Полностью перезапустите Expo Go и убедитесь, что задачи, блоки, серии и исключения сохранились в SQLite.

Web-данные после обновления страницы намеренно сбрасываются. Проверка SQLite на физическом iPhone остаётся отдельной ручной приёмкой и не может быть заменена браузерными тестами.
