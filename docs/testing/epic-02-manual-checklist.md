# Epic 02 — ручная проверка Backlog

## Браузерный прототип на Windows

1. В корне проекта выполните `npm run web` и откройте URL Expo из консоли.
2. Откройте вкладку `Backlog`. На корневом экране должны быть только три карточки и именно в таком порядке: «Напоминания», «Без проекта», «Проекты». Поиска и фильтров быть не должно.
3. Проверьте данные development-версии: в «Напоминаниях» есть «Позвонить в страховую», в «Без проекта» — «Сохранить статьи для чтения», а в «Проектах» — «Личное» и «Работа».
4. Нажмите `+`. В меню доступны только «Новый проект», «Новая задача» и «Новое напоминание». Создайте каждый из этих типов, указав только название. Новое напоминание должно появиться в превью первой карточки.
5. Откройте новую задачу, задайте описание и оценочную длительность, назначьте проект и сохраните. Отредактируйте её ещё раз, выбрав «Без проекта»; задача должна перейти в соответствующую категорию без потери описания и длительности.
6. На экране задачи добавьте подзадачу. У подзадачи нет команды добавления дочернего элемента и отдельного выбора проекта.
7. Откройте задачу, нажмите «Завершить» и вернитесь в список: задача и её подзадача должны исчезнуть из активного Backlog. У несвязанной задачи статус не меняется.
8. Для проекта нажмите «Завершить»: сам проект, все его задачи и подзадачи должны исчезнуть из активного Backlog.
9. Проверьте удаление: при отказе в диалоге элемент остаётся, при подтверждении задача удаляется вместе с подзадачами, а удаление проекта оставляет его задачи в категории «Без проекта».
10. Нажмите «Запланировать» у задачи или подзадачи. Должно появиться сообщение, что выбор даты и времени появится на следующем этапе; дата и время не назначаются.
11. У всех вложенных экранов проверьте кнопку «Назад». Она должна возвращать на предыдущий экран внутри вкладки Backlog.
12. Обновите браузерную страницу. Данные, созданные в браузере, должны сброситься: web-хранилище намеренно существует только в памяти страницы.

## iPhone через Expo Go

1. Подключите iPhone и Windows-компьютер к одной сети. В корне проекта выполните `npm start`, затем откройте QR-код в Expo Go.
2. На вкладке Backlog повторите пункты 2–11 из браузерного сценария: проверяются те же три карточки, создание, редактирование, перенос, подзадачи, каскадное завершение и подтверждённое удаление.
3. Создайте тестовую задачу с узнаваемым названием, полностью закройте Expo Go и снова откройте проект через запущенный Expo-сервер.
4. Убедитесь, что задача сохранилась. На iPhone данные Backlog хранятся локально в SQLite.

## Границы Epic 02

- Выбор времени, временные блоки, расчёт загрузки и автоматическое планирование появятся в Epic 03.
- Напоминание может хранить дату, период, повторение и оценочную длительность, но Epic 02 не строит по ним расписание.
- Нет авторизации, Microsoft 365, синхронизации, поиска, фильтров, импорта и сетевых запросов.
